# dotfiles — Fedora Sway

## Restaurar numa máquina nova

    git clone git@github.com:gabrielwt0/Dotfiles.git ~/dotfiles
    cd ~/dotfiles && ./restore.sh

## Atualizar o repositório

    ~/dotfiles/sync.sh
    git commit -m "descrição"
    git push
